HR Analytics Dashboard – Power BI

Overview
An interactive HR Analytics Dashboard built in Power BI to analyze employee attrition, workforce demographics, salary distribution, and department-level insights. The dashboard helps organizations monitor employee trends and improve HR decision-making.

Key Metrics
Total Employees: 1,417
Active Employees: 1,000
Attrition Count: 231
Attrition Rate: 16.3%
Average Age: 36.94

Features
Department-wise attrition analysis
Attrition by salary slab and job role
Employee age group distribution
Gender-based attrition insights
Experience vs attrition trend analysis
Interactive slicers for department and age group filtering

Tools Used
Power BI
DAX
Data Modeling
Data Visualization

Insights
Highest attrition observed in the Sales Department
Most employees belong to the 26–35 age group
Attrition is higher among employees with lower experience
Majority of attrition comes from mid-level salary slabs
Project Objective

To provide actionable HR insights for:
Employee retention
Workforce analysis
Attrition monitoring
Strategic HR planning
